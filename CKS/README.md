# CKS Study Program - Index

![The CKS Exam Fortress](./images/cks-00-exam-domain-map.jpg)

This folder contains the Certified Kubernetes Security Specialist study program. It follows the same numbered flow as the CKA folder: exam snapshot, research, topic refreshers, cheatsheets, drills and questions, mock exams, strategy, and the final visual references.

For administrator fundamentals that CKS builds on, see the [CKA Study Program](../CKA/README.md).
